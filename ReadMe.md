# ScreenTranslator

**Мгновенный перевод любого текста на экране — просто выдели область.**

Лёгкая утилита для Windows, которая живёт в трее: жмёшь горячую клавишу, выделяешь область экрана — и через долю секунды поверх неё появляется карточка с переводом. Никаких скриншотов, вставок в переводчик и лишних окон.

## Возможности

- **Мгновенное выделение** — как в снипчере: тянешь рамку прямо по экрану.
- **Live-перевод** — текст переводится ещё во время растягивания рамки, без лишнего клика.
- **Resize-хендлы** — можно точно подправить границы уже после выделения.
- **Перетаскиваемая карточка перевода** — расположи её там, где удобно, двойной клик вернёт на место.
- **Копирование в один клик** и **закрепление (pin)** карточки поверх окон.
- **Смена направления перевода** прямо на лету (кнопка со стрелками над рамкой).
- **DeepL API + бесплатный Google Translate fallback** — работает и без ключа.
- **Windows OCR / Tesseract** — используется системное распознавание текста Windows, либо fallback на Tesseract.
- **Поддержка нескольких мониторов** и корректный HiDPI.
- **Глобальный хоткей** с тройным резервированием: `RegisterHotKey → pynput → keyboard`.
- **Тёмная тема** и гибкие настройки через трей.

## Как это выглядит

1. Нажми `Ctrl+Shift+T` (настраивается).
2. Выдели область с текстом на экране.
3. Получи перевод в карточке прямо рядом с выделением.

## Установка

```bash
git clone https://github.com/yourname/screen-translator.git
cd screen-translator
pip install -r requirements.txt
python screen_translator.py
```

### Зависимости

```
PyQt6
Pillow
pywinrt (для Windows OCR) — опционально
pytesseract — опционально, fallback OCR
pynput / keyboard — опционально, fallback для хоткеев
```

> Для лучшего качества перевода добавь бесплатный DeepL API-ключ в **Настройках** (иконка в трее). Без ключа перевод идёт через Google Translate.

## Настройки

Доступны через иконку в трее:

| Параметр | Описание |
|---|---|
| DeepL API-ключ | Опционально, повышает качество перевода |
| Язык перевода | 11 языков на выбор |
| Глобальный хоткей | Любая комбинация, например `ctrl+shift+t` |
| Интервал live-OCR | 250–3000 мс |
| Тёмная тема | Вкл/выкл |

## Технологии

- **PyQt6** — UI, оверлей выделения, нативная перехватка хоткеев
- **Pillow** — обработка изображений перед OCR
- **Windows.Media.Ocr (WinRT)** — быстрое офлайн-распознавание текста
- **DeepL API / Google Translate** — перевод
